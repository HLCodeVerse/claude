Essential Endpoints


          
          

            

              POST
              /message/sendText/:instanceName
            

            
Sends a text message to any phone number (e.g. 15551234567).

            
{
  "number": "15551234567",
  "text": "Hello from my app! 🚀"
}

          


          
          

            

              POST
              /message/sendMedia/:instanceName
            

            
Sends an image or video attachment via public URL or direct Base64 string.

            
{
  "number": "15551234567",
  "mediatype": "image",
  "mimetype": "image/png",
  "media": "https://example.com/photo.png",
  "caption": "Monthly statement 📸"
}
// Note: "media" also accepts raw base64 data URI: "data:image/png;base64,iVBORw..."

          


          
          

            

              POST
              /message/sendWhatsAppAudio/:instanceName
            

            
Sends an audio file rendered as a native WhatsApp recorded Voice Note (PTT with waveform & green mic).

            
{
  "number": "15551234567",
  "audio": "https://example.com/audio/voice-note.mp3",
  "ptt": true
}
// Note: "audio" also accepts "data:audio/mp3;base64,..."

          


          
          

            

              POST
              /message/sendMedia/:instanceName
            

            
Sends documents (PDF, Word, Excel, Zip, TXT) with custom filename and icon.

            
{
  "number": "15551234567",
  "mediatype": "document",
  "mimetype": "application/pdf",
  "media": "https://example.com/files/invoice-102.pdf",
  "fileName": "Invoice_Oct_2026.pdf"
}
// Note: "media" also accepts "data:application/pdf;base64,..."

          


          
          

            

              GET
              /instance/connectionState/:instanceName
            

            
Verifies whether WhatsApp is connected ("state": "open").

          

        

      

    


    
    
    
    

      

        

          

            
          

          

            
WhatsApp Anti-Ban & Bulk Messaging Guide

            

              Will WhatsApp suspend my account if I send bulk messages? YES, if done improperly. Here is how to keep your phone number 100% safe.
            

          

        


        
        

          

            
            The #1 Cause of WhatsApp Bans: User "Report & Block"
          

          

            When recipients receive a message from an unsaved number, WhatsApp shows a prominent "Report & Block" button. If just 3 to 5 users report your message within a few hours, WhatsApp's automated AI will immediately ban your number.
          

        


        
        

          

            

               1. Random Delays (5–15 Seconds)
            

            

              Never send 50 messages in the same second. In your sending loop, add a random wait of 5 to 15 seconds between each contact.
            

          


          

            

               2. Number Warm-Up Schedule
            

            

              Days 1–3: Max 20 msgs/day. Days 4–7: Max 50 msgs/day. Week 2+: Gradually scale up to 150–300 msgs/day.
            

          


          

            

               3. Text Spintax & Personalization
            

            

              Never send identical text to 500 people. Vary greetings (Hi {name}, Hello {name}) and personalize content.
            

          


          

            

               4. Easy Opt-Out Notice
            

            

              Always end with "Reply STOP to unsubscribe". Users who type STOP won't report your number to WhatsApp!
